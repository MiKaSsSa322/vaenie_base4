# Changelog

## 1.0.2
- Повышена частота генерации всех шести построек.
- Полевые укрытия и наблюдательные посты теперь встречаются заметно чаще; крупные базы остаются редкими.

## 1.0.1
- Исправлен краш при создании мира: во все определения структур добавлено обязательное поле `spawn_overrides`.
- Версия мода повышена до 1.0.1.

## 1.0.0
- Первый самостоятельный релиз-кандидат для Forge 1.20.1.
- Добавлены шесть ванильных структур: землянка, наблюдательный пост, малый лагерь,
  укреплённый бункер, укреплённый лагерь и большая база.
- Добавлены data-driven worldgen structure, structure_set и template_pool.
- Добавлены офлайн-валидатор NBT/JSON и CI workflow для Forge-сборки.

## 1.0.3
- Существенно увеличена частота генерации всех типов построек: уменьшены spacing/separation.
- Добавлен поиск ближайшей постройки командами `/nearestbuilding` и `/nearest_building` (через `/locate` по общему тегу).
