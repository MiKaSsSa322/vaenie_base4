# Отчёт проверки Frontier: Military Installations 1.0.0

Дата проверки: 25.11.2026

## Успешно выполнено

- Проверены все 18 JSON-файлов worldgen: синтаксис корректен.
- Проверены 6 сжатых NBT-шаблонов: заголовок, структура тегов, размеры, палитры,
  индексы блоков и координаты находятся в допустимых пределах.
- Проверены ссылки `structure` → `template_pool` → NBT-шаблон.
- Проверено отсутствие повторяющихся координат блоков в каждом шаблоне.
- Java-класс прошёл синтаксическую компиляцию `javac --release 17` с минимальной
  заглушкой аннотации Forge `@Mod`.

## Не выполнено в текущей среде

- `gradle build` против настоящих ForgeGradle/Minecraft зависимостей.
- Запуск Minecraft Forge 1.20.1 и наблюдение за генерацией структур в игровом мире.

Причина: Gradle не установлен, а сетевой доступ для загрузки Gradle и Forge/Minecraft
зависимостей недоступен. Проверка Java с заглушкой подтверждает только синтаксис
исходного класса, но не заменяет настоящую Forge-сборку.

Для завершения проверки используй GitHub Actions workflow в `.github/workflows/build.yml`
или собери проект локально командами из `README_RU.md`. В игре проверяй на новых чанках.
